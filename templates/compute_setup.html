Add a Compute Worker

Install another isolated CPU worker on a Linux AMD64/ARM64 computer. The worker makes an outbound HTTPS/WSS connection; no incoming ports need to be opened.

The installer requires Docker Engine, Docker Compose v2, Python 3 and curl. It never installs Docker silently, modifies existing Compose projects or receives Docker socket access inside the worker.

Auto Maximum measures the actual Linux host's free RAM, CPU and Docker storage. It leaves a safety reserve. Switch to Manual for exact limits.

New workers cannot process private prompts unless you explicitly enable trust after enrollment. Keep the one-time code confidential.
