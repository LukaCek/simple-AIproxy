Add a Compute Worker

Create an unprivileged Linux AMD64/ARM64 Docker worker. All inference and model settings are managed later in SimpleAI Proxy.

Prerequisite: proxy endpoints and the multi-architecture GHCR worker image must already be deployed. Keep all private data on trusted workers only.

The worker cannot use more than these CPU/RAM limits. The disk budget is enforced by the application, not a hard filesystem quota. Choose resources that leave enough capacity for the host.

Your worker installation

The one-time enrollment token expires at . Both files must be saved in the same folder on the Docker host.

The .env contains a temporary credential. Never publish it. Delete the token from .env after successful enrollment; the worker saves its identity in a private volume.

Run in the folder containing both files:

chmod 600 .env
docker compose config --quiet
docker compose pull
docker compose up -d
docker compose logs --tail=50 compute-worker

Then check the Compute Nodes dashboard. Do not grant access to private prompts unless you trust the computer's operator.
